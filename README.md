# 📊 Projeto Pandas

Projeto desenvolvido para praticar **análise e visualização de dados com Python e Pandas**.

## 📌 Sobre o projeto

O projeto utiliza dados de **voos e condições meteorológicas de aeroportos**, organizados em arquivos CSV dos anos de **2023, 2024 e 2025**.

A análise é realizada com Python e Pandas, permitindo consultar, organizar e interpretar os dados.

## 🛠️ Tecnologias

* Python
* Pandas
* HTML
* CSS
* CSV

## 📂 Dados analisados

* ✈️ Dados de voos
* 🌦️ Dados meteorológicos de aeroportos
* 📅 Período de 2023 a 2025

## 🎯 Objetivo

Praticar conceitos de **Análise de Dados com Python**, utilizando o Pandas para trabalhar com dados reais e transformá-los em informações mais fáceis de consultar e interpretar.
